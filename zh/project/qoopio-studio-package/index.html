概念

QOOPIO Studio 的識別以圓潤、相互咬合的字形，搭配鮮明的萊姆綠與銀色。包裝把這套識別化為一件實體物件：透明盒身像標本一樣框住標誌的網格，讓品牌在開箱之前就已經被看見。

建模與動畫

由 QOOPIO Studio 設計，並全程以 Blender 建模與渲染。每個零件都依實際尺寸製作——透明 PVC 盒、銀色燙金，以及以 Pantone 877C / 2296C + 803C / 黑色印刷的 150gsm 米白紙——再調整厚度、倒角與反光，讓每種材質各有各的質感。一段循環短動畫讓盒身旋轉、銀色燙金捕捉光線，呈現靜態圖看不到的變化。
